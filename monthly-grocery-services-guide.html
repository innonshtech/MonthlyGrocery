2. Google Maps Platform & Location APIs

Critical for Customer Address Pinning, Merchant Delivery Radius, and Service Area Verification

Required

The Monthly Grocery customer flow relies heavily on exact geolocation for checking serviceability (e.g. Pune, Hinjewadi, Kothrud), pinning delivery apartments, calculating delivery distances from the assigned merchant hub, and geofencing.

Google API Requirement Application Flow Purpose
Places API (New / Autocomplete)
 Required Customer & Merchant Apps Powers search autocomplete when users type their building, society, or street name during address creation and onboarding.
Geocoding & Reverse Geocoding
 Required Map Pin Screen Converts GPS coordinates (lat/lng) into readable addresses (Flat, Society, Street, Pincode) when the user moves the map marker.
Maps SDK for Android & iOS
 Required Mobile Native Maps Renders the interactive Google Map inside the React Native Customer & Merchant apps for visual address confirmation.
Distance Matrix API
 Recommended Order & Delivery Routing Calculates the exact road distance between the customer’s address and the merchant store to enforce delivery zones and calculate delivery fees.
⚠️
Google Maps Security Best Practice: Create separate restricted API keys in Google Cloud Console:
  • Android Key: Restricted by Package Name (com.monthlygrocerymobile) + SHA-1 Signing Fingerprint.
  • iOS Key: Restricted by iOS Bundle Identifier (com.monthlygrocerymobile).
  • Backend / Web Key: Restricted by Server IP Address or HTTP Referrers.

5. SMS OTP & DLT Compliance (India Telecom)

Mandatory telecom registrations to deliver transactional OTPs to Indian mobile numbers

Required for Production
Service / Component Provider Options Requirement Description & Setup Steps
DLT Principal Entity Reg
TRAI Regulatory Mandate
 Jio DLT / Vilpower / Airtel DLT Mandatory (India) Register business entity on telecom portal with PAN, GST, and Certificate of Incorporation. Approx cost: ₹5,000 + GST.
SMS Header (Sender ID)
e.g. MNTHGR / INNSH
 Approved via DLT Portal Mandatory 6-character alpha sender ID under which OTP and order update SMS will be delivered to customers.
SMS Gateway Service
API Integration
 Fast2SMS / MSG91 / Twilio / Kaleyra Required Direct REST API integration into express-backend/src/routes/auth.ts to trigger high-speed 6-digit OTPs within 3 seconds.
✅
Development vs Production Mode: The project currently has a development bypass flag (DEV_OTP_BYPASS=true). For live production launch, the SMS gateway API key and DLT template ID must be plugged into backend environment variables.

6. Payment Gateway Integration

Online Payment Processing (UPI, Cards, NetBanking, AutoPay)

🚫 Not in Scope for Phase 1 (Deferred to Phase 2)
📋
Phase 1 Operating Model (Cash on Delivery / Direct Settlement):

For the Phase 1 Launch, online payment gateway integration (Razorpay / PhonePe / Cashfree) is NOT in scope. Orders will be handled via Cash on Delivery (COD) / Pay on Delivery / Direct Store Settlement. No payment aggregator merchant accounts, banking API credentials, or webhook keys are required for the initial deployment.

Phase 2 Target Service Supported Modes Phase 1 Status Phase 2 Roadmap Note
Razorpay / PhonePe / Cashfree
Payment Gateway Aggregator
 UPI Intent, UPI AutoPay, Debit/Credit Cards, Net Banking Not in Scope for Phase 1 Will be integrated in Phase 2 after initial market validation. In Phase 2, merchant business KYC (GSTIN, Current Account, Cancelled Cheque) and webhook verification will be enabled.
🔔

7. Push Notifications & Event Alerts

Mobile Background Push Alerts for Order Updates & Promotions

🚫 Not in Scope for Phase 1 (Deferred to Phase 2)
📋
Phase 1 Notification Strategy:

For the Phase 1 Launch, automated mobile push notifications (FCM & APNs) are NOT in scope. Customers and Merchants will track order updates directly through the Live In-App Order Tracker Screen and SMS Transactional Alerts. Firebase Cloud Messaging (FCM) v1 server keys and APNs Auth Keys (.p8) will be configured in Phase 2.

Notification Service Target Devices Phase 1 Status Phase 2 Roadmap Note
Firebase Cloud Messaging (FCM) & APNs
Google FCM v1 + Apple APNs
 Android & iOS Push Alerts Not in Scope for Phase 1 Phase 1 relies on In-App UI state polling and SMS. Background push notification triggers for order dispatch and monthly basket reminders will be activated in Phase 2.
