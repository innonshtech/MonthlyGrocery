# MonthlyGrocery Partner — Store & Inventory Manager

Dedicated React Native Mobile Application for Kirana Store Partners and Regional Merchants.

## Features
- **Live Orders Dashboard**: Instant incoming orders stream with status progression (`Pending` ➔ `Confirmed` ➔ `Packing` ➔ `Out for Delivery` ➔ `Delivered` / `Cancelled`).
- **1-Click Customer Dialing**: Direct phone dialer shortcut to contact customers for address confirmation.
- **Inventory & Stock Management**: Real-time stock counts, In-Stock/Out-of-Stock instant switches, and quick modal to edit store selling price & stock quantities.
- **Master SKU Catalog**: Browse central products to request new SKUs or configure store margins.
- **Store Analytics**: Daily sales, average order values, and fulfillment breakdown.
- **Store Settings & Support**: Store profile details and direct WhatsApp Super Admin support.

## Running Locally

1. Ensure Express backend is running on `http://localhost:8001`.
2. Start Metro bundler:
```bash
npm start
```
3. Run on Android:
```bash
npm run android
```
